The Core Architectural Idea

Modern video codecs (H.264, HEVC, AV1, VVC) were engineered for camera footage: band-limited photographic scenes where spatial frequencies decay smoothly. They rely on 2D spatial Discrete Cosine/Sine Transforms (DCT/DST) and 4:2:0 chroma subsampling.

On computer screen content (software consoles, IDEs, spreadsheets, vector typography, cloud desktops), sharp edges and text glyphs represent mathematical step discontinuities. When transformed with truncated 2D Fourier bases, they suffer from the Wilbraham-Gibbs phenomenon—producing mandatory ringing ripples, mosquito halos, and blurred typography. Furthermore, 4:2:0 subsampling decimates single-pixel syntax-highlighted code.

TimeFlowCodec eliminates 2D spatial block transforms entirely. Instead, each pixel's intensity evolution over time $s_{x,y}(t)$ is modeled directly using closed-form Ordinary Least Squares (OLS) regression $s(t) = a + b \cdot t$, combined with adaptive per-pixel mode decision (Static, Linear Trend, Fallback) and a low-latency streaming container.

⚡ Zero Gibbs Ringing

Because no spatial frequency basis is truncated, spatial text contours and window borders remain mathematically razor-sharp at any compression level.

🎨 Native 4:4:4 Full-Color Fidelity

Independent per-channel modeling prevents color bleeding and retains exact syntax highlighting and subpixel font rendering.

🧠 O(1) Working Memory State

No multi-frame Decoded Picture Buffer (DPB) or 2D spatial line buffers required. Frames are synthesized independently in parallel raster scanlines.

🚀 Ultra-Fast ANSI C99 Reference Core

Single-threaded C99 decoder achieves over 3,300 FPS at 240p, 970 FPS at 368p, and 150 FPS at 720p HD on Apple Silicon (M4).

Quickstart & CLI Usage

Install the Python package (includes the CLI, GUI, and reference decoder):

pip install timeflowcodec

Encode a screen recording into a .tfc container:

tfc encode input.mp4 output.tfc --preset screen

Launch the interactive desktop player:

timeflowplay output.tfc

Stream live macOS desktop frames directly to TFC via native ScreenCaptureKit:

python -m timeflowcodec.capture live_session.tfc --fps 30 --scale 1280
