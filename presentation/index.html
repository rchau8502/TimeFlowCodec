Spatial Block Partitioning

Subdivides frames into square blocks (4×4 to 128×128) and applies 2D DCT/DST spatial frequency transforms.

Chroma Subsampling (4:2:0)

Decimates color resolution by 75% to exploit natural human visual limits—assuming high chromatic frequencies are unnoticeable.

1. Gibbs Ringing at Text Edges

2D DCT assumes smooth continuous waveforms. Sharp text step edges generate infinite high-frequency harmonics. Quantization truncates these, causing severe mosquito halo ringing around text.

2. Chroma Bleeding

4:2:0 subsampling decimates color resolution by 75%, blurring syntax-highlighted code and colored icons into unreadable smudges.

3. Block Boundary Discontinuities

Independent block quantization breaks continuous horizontal and vertical UI lines, fracturing window frames and panels.

4. Motion Search Waste for Micro-Updates

A 10-pixel blinking cursor triggers quadtree partition headers and motion searches across the entire 4K frame.

Spatial Block Transforms (x264 / x265)

  • 2D DCT Basis Truncation: Triggers >10% overshoot and oscillatory ripples across the 8-pixel block.
  • Chroma Decimation (4:2:0): Blurs colored syntax dots and colored borders.

TimeFlowCodec (1D Temporal Model)

  • Zero Spatial Transforms: Discarding spatial transforms preserves exact discrete step edges.
  • Native 4:4:4 RGB: Razor-sharp 1-pixel font stems and syntax highlighting without color bleeding.

The Per-Pixel Temporal Hypothesis

Treat the temporal luminance trajectory of each pixel s(t) across frames t = 0...T-1 as an independent 1D continuous function.

  • Zero Spatial Transforms: No block boundaries, no Gibbs ringing!
  • Native Full-Resolution RGB: Pristine text edges with zero chroma decimation (4:4:4).
  • Deterministic Linear Time: Closed-form O(T) ordinary least squares regression without motion searches.

Operational Coding Modes

  • MODE_CONST: s(t) = a (1 byte stored per pixel)
  • MODE_LINEAR: s(t) = a + bt (2 parameters stored)
  • MODE_MATRIX: Low-rank SVD factorization (u · vT) for correlated tiles
  • MODE_RAW: Fallback sample buffer for abrupt changes

Closed-Form Estimators

For discrete time index set t ∈ {0, ..., T-1}:

CONST Model: â = (1 / T) * Σ s_t = s̄

LINEAR Model:
b̂ = 12 * Σ (t - t̄) s_t / [T(T² - 1)]
â = s̄ - b̂ * t̄

Evaluated in exactly O(1) elementary operations once T frames are ingested!

Streaming Accumulation Engine

  • Maintains only two accumulators: A₁ = Σ s_t and A₂ = Σ t · s_t
  • O(T) Total Time: Ingests frames in a single streaming pass
  • O(1) Working Memory: No need to store full uncompressed video windows in memory
  • Embarrassingly Parallel: Each pixel is mathematically independent

Variance-Normalized Error Ratio (r)

r = MSE(s, ŝ_linear) / [Var(s) + ε]

Decision Rules

  1. If r ≤ τ (Error Tolerance):
    • If |b̂| < θ_slope: Select CONST (store a)
    • Else: Select LINEAR (store a, b)
  2. Else (r > τ): Reject parametric hypothesis → Fallback to RAW or MATRIX.

Rate-Distortion Tuning

  • Parameter τ: Primary rate-distortion knob (analogous to CRF or QP in hybrid codecs)
  • Typical Range: τ ∈ [10⁻⁵, 10⁻²]
  • Slope Gating (θ = 0.001): Prevents wasting 2 bytes on imperceptible slopes
  • Guaranteed Error: Strict mathematical error bound per pixel

Container Innovations

  • Bounded Chunk Windows: Self-contained 24-48 frame chunks with CRC32 verification
  • 2-Bit RLE Mode Maps: Packs 4 pixel decisions per byte, compressed with byte RLE
  • Quantized Integer Payloads: Quantized uint8 intercept a and int16 slope b (Zero float32 arrays on disk!)
  • Rational Frame Timing: Exact fractional FPS (N/D) prevents audio drift
  • Zstandard Entropy: Real-time zstd compression (>1.2 GB/s decompression)

Bounded-RAM & Memmap Fallback

  • Fallback raw tiles can consume massive RAM on 4K footage
  • Encoder estimates required buffer: M_est = (T · H · W · C) / 1024² MiB
  • If M_est > max_ram_mb: Allocator automatically creates a disk-backed numpy.memmap
  • Keeps RAM strictly bounded regardless of duration

Vectorized SIMD Reconstruction

  • Early Python loops consumed 88% of decode time (17.5s on a test clip)
  • Vectorized temporal broadcasting:
    V̂(t, y, x) = A(y, x) + B(y, x) · t
  • Maps to native C/SIMD fused multiply-add (FMA)
  • 7× Decoding Speedup: Delivers >240 FPS at 1080p!

HEVC-SCC (MPEG / ITU-T Extension)

  • Intra Block Copy (IBC): Reconstructs blocks from prior 2D regions; requires huge 2D search loops.
  • Encoder Complexity: +300% to +1000% slower encoding than baseline HEVC.
  • The Silicon Barrier: Virtually zero hardware decoder silicon in consumer mobile, Apple, or Intel GPUs.
  • Software Fallback: High battery drain and thermal throttling on client devices.
  • Quadtree Syntax: Still incurs block split headers and rate-distortion search overhead.

TimeFlowCodec (Temporal Paradigm)

  • 1D Temporal Regression: Replaces 2D block searches with closed-form streaming accumulation.
  • Deterministic O(T) Encoding: Single streaming pass; O(1) working RAM per pixel; zero motion vectors.
  • Universal SIMD Decoding: Runs natively on standard CPU SIMD (FMA) and WebGPU/Metal compute shaders.
  • Extremely Low Power: >240 FPS decode throughput with <5% CPU utilization and 75% lower memory bandwidth.
  • Full 4:4:4 RGB: Native text clarity without chroma decimation.

The Operational Boundary

  • Sensor noise and optical motion break linearity (r > τ)
  • >42% Fallback to RAW: Bitrates rise to 1.2-7.8 Mbps
  • Block-based hybrid codecs (HEVC/AV1) dominate here due to in-loop DCT noise filtering and spatial motion compensation
  • Crucial Research Takeaway: TFC is an optimized domain-specific codec for synthetic, UI, and animation video.

Summary of Contributions

  1. Formalized Temporal Regression Video Coding: Replaced 2D spatial block transforms with closed-form O(T) OLS models, eliminating text ringing and block artifacts.
  2. Full-Resolution RGB Text Fidelity: Preserved single-pixel text stems and color contrast with native 4:4:4 representation.
  3. Bounded-Memory v5 Streaming Container: Designed chunked framing with CRC32 checks, rational frame timing, and multiplexed audio.
  4. High-Throughput Open Source Implementation: Vectorized C/SIMD decoding delivering >240 FPS and comprehensive desktop tooling.
