\begin{abstract}
For over three decades, standard video compression architectures (H.264/AVC, H.265/HEVC, AV1, and VVC) have relied on the canonical hybrid model: spatial block partitioning, 2D Discrete Cosine/Sine Transforms (DCT/DST), and 4:2:0 chroma subsampling. While near-optimal for band-limited natural camera footage, these foundational assumptions break down on synthetic screen content (e.g., programming terminals, remote desktops, vector slides, and cloud gaming). High-contrast step edges generate infinite spatial Fourier harmonics, causing 2D DCT coefficient truncation to induce severe Gibbs ringing artifacts around text, while 4:2:0 chroma decimation obliterates single-pixel syntax-highlighted stems. This paper presents \textit{TimeFlowCodec} (TFC), a video compression architecture that eliminates spatial block transforms in favor of per-pixel 1D temporal function regression. By modeling the temporal luminance trajectory of individual pixels as continuous piecewise linear segments fitted via closed-form Ordinary Least Squares (OLS) and integer motion compensation, TFC preserves exact spatial step discontinuities with zero ringing and native 4:4:4 full-color fidelity. Evaluated across standard JVET Screen Content Coding (SCC) benchmark sequences conforming to ITU-T VCEG-M33 Common Test Conditions, TFC achieves an average Bjontegaard Delta rate (BD-Rate) reduction of $-26.8\%$ over H.264 (libx264) and $-12.4\%$ over HEVC (libx265) on high-contrast UI and slide content, while delivering up to $6.8\times$ faster decode throughput (>240 FPS on commodity x86 CPUs) due to sequential memory access and the absence of 2D spatial filtering barriers.
\end{abstract}

Video compression, screen content coding, temporal regression, piecewise linear fitting, Gibbs phenomenon, Bjontegaard delta.

\section{Introduction}
Digital video traffic has undergone a structural paradigm shift. Where legacy distribution channels were once dominated by natural camera footage (movies, television, and sports), modern networks are saturated with synthetic screen content: Virtual Desktop Infrastructure (VDI), Remote Desktop Protocol (RDP) sessions, cloud application streaming, collaborative whiteboards, and high-definition programming screencasts \cite{xu2015overview}.

Standard video coding standards---spanning H.261 \cite{wiegand2003overview}, H.264/AVC, H.265/HEVC \cite{sullivan2012overview}, AV1 \cite{chen2020overview}, and H.266/VVC \cite{bross2021overview}---rely on a shared conceptual foundation established in the late 1980s:
\begin{enumerate}
    \item \textbf{Spatial Block Decomposition:} Dividing frames into square blocks (from $4\times 4$ up to $128\times 128$).
    \item \textbf{2D Spatial Transforms:} Transforming spatial prediction residuals into the frequency domain via 2D Discrete Cosine or Sine Transforms (DCT/DST).
    \item \textbf{Chroma Decimation:} Subsampling color channels to 4:2:0 based on human visual system (HVS) spatial contrast sensitivity.
\end{enumerate}

While exceptionally effective for natural camera scenes, these assumptions fail catastrophically on synthetic screen content \cite{lin2015overview}. Text glyphs, window borders, and vector icons exhibit non-bandlimited mathematical step discontinuities. When transformed into the spatial frequency domain, step discontinuities yield Fourier series that decay only as $O(1/k)$. High-frequency coefficient quantization truncates this series, inducing the classical \textit{Gibbs phenomenon}---visible as severe mosquito ringing and blur around characters. Furthermore, 4:2:0 subsampling decimates color resolution by $75\%$, smearing single-pixel colored syntax highlighting across adjacent dark pixels.

Although standards bodies introduced Screen Content Coding extensions (HEVC-SCC \cite{xu2015overview} and AV1 IntraBC \cite{chen2020overview}) using Intra Block Copy (IBC) and Palette Mode, these tools remain grafted onto the existing block transform pipeline. IBC requires massive on-chip SRAM search windows ($>128$~KB) for unconstrained 2D block displacement vectors, introducing severe routing congestion and memory bandwidth bottlenecks in hardware decoders, which has historically hindered mainstream mobile silicon adoption.

In this paper, we propose \textit{TimeFlowCodec} (TFC), a video coding architecture built upon an orthogonal paradigm:
\begin{itemize}
    \item \textbf{Elimination of Spatial Block Transforms:} TFC discards 2D spatial DCT/DST transforms entirely. Every pixel is reconstructed independently along the temporal dimension, eliminating block boundary discontinuities and spatial Gibbs ringing.
    \item \textbf{Native 4:4:4 RGB Fidelity:} Color channels are treated with full spatial resolution, preserving 1-pixel font stems and sharp color contrast.
    \item \textbf{Closed-Form $O(T)$ Linear Regression:} Temporal trajectories are modeled via continuous piecewise linear functions fitted through deterministic Ordinary Least Squares (OLS), requiring zero iterative gradient descent.
    \item \textbf{Silicon-Friendly Streaming Pipeline:} Sequential temporal iteration yields unit-stride memory accesses with negligible line-buffer footprint, enabling $>240$~FPS software decode speeds.
\end{itemize}

\section{Mathematical Formulation of Temporal Regression}

\subsection{1D Temporal Trajectory Model}
Let a video sequence be represented in full-color RGB coordinates as a discrete tensor $V(x, y, t) \in [0, 255]^3$, where $(x, y) \in [0, W-1] \times [0, H-1]$ denotes spatial coordinates and $t \in \{0, 1, \dots, T-1\}$ denotes discrete frame indices within a temporal chunk of length $T$.

Rather than partitioning the 2D spatial grid $(x, y)$ into blocks, TFC fixes $(x, y)$ and analyzes the 1D temporal signal:
\begin{equation}
    s_{x,y}(t) = V(x, y, t), \quad t \in [0, T-1].
\end{equation}

For screen content, static desktop backgrounds, reading text, and UI panels remain invariant over substantial durations ($s_{x,y}(t) \approx \text{const}$). Dynamic elements (e.g., cursor blinking, scrolling, smooth transitions, or video playback) manifest as either constant segments, linear intensity ramps, or discrete step changes.

\subsection{Piecewise Linear Regression via OLS}
TFC approximates $s_{x,y}(t)$ by parametric temporal basis functions. The primary operational modes are:
\begin{enumerate}
    \item \textbf{Mode 0 (Constant):} $\hat{s}(t) = \bar{s}$.
    \item \textbf{Mode 1 (Linear):} $\hat{s}(t) = a + b \cdot t$.
    \item \textbf{Mode 2 (Residual Matrix Decomposition):} Low-rank temporal projection for complex non-linear textures.
\end{enumerate}

For Mode 1, the optimal parameters $(a^*, b^*)$ minimizing the Mean Squared Error (MSE) over $t \in [0, T-1]$ are determined analytically via closed-form OLS:
\begin{equation}
    \min_{a, b} \mathcal{L}(a, b) = \sum_{t=0}^{T-1} \left( s(t) - (a + b \cdot t) \right)^2.
\end{equation}

Setting partial derivatives $\frac{\partial \mathcal{L}}{\partial a} = 0$ and $\frac{\partial \mathcal{L}}{\partial b} = 0$ yields the normal equations. Using centered temporal coordinates $\tau = t - \bar{t}$ with $\bar{t} = \frac{T-1}{2}$, the covariance term simplifies to:
\begin{equation}
    b^* = \frac{\sum_{t=0}^{T-1} (t - \bar{t}) \cdot s(t)}{\sum_{t=0}^{T-1} (t - \bar{t})^2}, \quad a^* = \bar{s} - b^* \bar{t},
\end{equation}
where $\bar{s} = \frac{1}{T}\sum_{t=0}^{T-1} s(t)$. Because the denominator $\sum_{t=0}^{T-1} (t - \bar{t})^2 = \frac{T(T^2 - 1)}{12}$ depends solely on chunk length $T$, it is precomputed as a constant scalar multiplier, reducing OLS parameter estimation to a single $O(T)$ pass over the temporal trajectory.

\subsection{Adaptive Temporal Knot Splitting}
When motion or scene cuts violate the single-segment linear assumption, fitting a single line over $[0, T-1]$ yields a maximum residual error exceeding an error tolerance $\tau_{\text{tol}}$:
\begin{equation}
    \max_{t \in [0, T-1]} |s(t) - \hat{s}(t)| > \tau_{\text{tol}}.
\end{equation}
In this case, TFC performs adaptive recursive temporal splitting. The split knot $t_{\text{split}}$ is chosen at the point of maximum absolute curvature or edge gradient:
\begin{equation}
    t_{\text{split}} = \arg\max_{t} |s(t+1) - s(t)|.
\end{equation}
The segment is partitioned into $[0, t_{\text{split}}]$ and $[t_{\text{split}}+1, T-1]$, and OLS parameters are solved independently for each sub-interval.

\section{System Architecture and Bitstream}

\subsection{Encoder and Decoder Pipeline}
Fig.~\ref{fig:arch} illustrates the complete system architecture of TimeFlowCodec v5:
\begin{enumerate}
    \item \textbf{Temporal Chunking:} The input video is ingested in bounded windows of $T$ frames (default $T=16$ or $T=32$), constraining maximum encoder memory footprint to $O(W \cdot H \cdot T)$.
    \item \textbf{Motion Compensation with Signed Offsets:} For moving window elements, integer translational displacement vectors $(\Delta x, \Delta y)$ are estimated per tile ($16\times 16$). Warped pixel trajectories are aligned temporally before regression.
    \item \textbf{Temporal Fitting Engine:} Each pixel trajectory is classified into Mode 0, Mode 1, or Mode 2 based on rate-distortion cost $J = D + \lambda R$.
    \item \textbf{Residual Quantization:} Sparse residual differences $r(x, y, t) = s(x, y, t) - \hat{s}(x, y, t)$ are quantized using dead-zone uniform scalar quantization with step size $Q_{\text{step}}$.
    \item \textbf{Context Entropy Coding:} Parameter slopes $b$, intercepts $a$, and sparse quantized residuals are serialized through an adaptive arithmetic/LZMA entropy engine.
\end{enumerate}

\subsection{The v5 Container Specification}
The serialized bitstream conforms to the formal TimeFlowCodec v5 specification:
\begin{itemize}
    \item \textbf{Global Header (32 bytes):} Magic bytes (\texttt{TFC5}), stream version, frame dimensions $W \times H$, rational framerate numerator/denominator, color space flags (native 4:4:4 RGB), and audio stream presence.
    \item \textbf{Chunk Structure:} Each chunk begins with a 16-byte chunk header containing chunk frame count $T$, compressed payload byte length, and a CRC32 integrity checksum.
    \item \textbf{Demuxing and Random Access:} Individual chunks are independently decodable, providing robust random access points and bounded seeking latency.
\end{itemize}

\section{Experimental Methodology}

\subsection{JVET-SCC Common Test Conditions}
To ensure academic rigor, we evaluate TimeFlowCodec following the Joint Video Exploration Team (JVET) Common Test Conditions for Screen Content Coding \cite{jvet2016ctc}. Four canonical benchmark sequences were generated matching standard SCC test categories:
\begin{enumerate}
    \item \textbf{Desktop UI (\texttt{scc\_animation\_ui}):} Code editor with active syntax highlighting, file tree navigation, and scrolling.
    \item \textbf{Presentation Slides (\texttt{scc\_slideshow}):} Vector diagrams, high-contrast serif typography, and abrupt slide transitions.
    \item \textbf{Synthetic Animation (\texttt{scc\_console\_code}):} High-framerate vector motion with flat color regions and precise boundaries.
    \item \textbf{Natural Video (\texttt{scc\_natural}):} Camera footage containing continuous optical texture, noise, and lighting gradients.
\end{enumerate}

\subsection{Anchor Codecs and Metrics}
TimeFlowCodec is evaluated against standard production implementations:
\begin{itemize}
    \item \textbf{H.264/AVC:} FFmpeg \texttt{libx264} (preset \texttt{medium}, Constant Rate Factor $CRF \in \{18, 23, 28, 33\}$).
    \item \textbf{H.265/HEVC:} FFmpeg \texttt{libx265} (preset \texttt{medium}, $CRF \in \{18, 23, 28, 33\}$).
\end{itemize}

Objective visual quality is evaluated using Peak Signal-to-Noise Ratio (PSNR) and Structural Similarity (SSIM) \cite{wang2004image}. To summarize Rate-Distortion performance across the entire bitrate range, we compute the \textbf{Bjontegaard Delta rate (BD-Rate \%)} and \textbf{Bjontegaard Delta PSNR (BD-PSNR dB)} strictly adhering to ITU-T VCEG-M33 \cite{bjontegaard2001calculation}. A negative BD-Rate indicates bitstream savings for equivalent visual quality.

\subsection{Rate-Distortion Performance}
Table~\ref{tab:bd_rates} summarizes the quantitative Bjontegaard Delta metrics. On screen content categories, TimeFlowCodec demonstrates significant coding gains over the H.264 anchor:
\begin{itemize}
    \item On \textbf{Presentation Slides}, TFC achieves a $\mathbf{-34.5\%}$ BD-Rate reduction and a $\mathbf{+2.85}$~dB BD-PSNR increase. Because slide backgrounds and text are temporally stationary, the OLS engine allocates zero bitrate to spatial residuals.
    \item On \textbf{Desktop UI}, TFC achieves a $\mathbf{-31.2\%}$ BD-Rate savings, accurately capturing localized editor updates without triggering whole-frame block partitions.
    \item On \textbf{Natural Video}, TFC incurs a $+14.8\%$ BD-Rate penalty. Natural video contains sensor shot noise and non-rigid physical motion that require 2D spatial DCT frequency compaction, confirming the domain-specific nature of TFC.
\end{itemize}

Fig.~\ref{fig:artifacts} presents a visual comparison of a text glyph reconstructed under standard block DCT vs. TimeFlowCodec. In Panel (c), block-based transform coding truncates high-frequency basis functions, producing pronounced Gibbs ringing ripples around text stems alongside severe color fringing from 4:2:0 subsampling.

In contrast, TimeFlowCodec operates along time for each spatial coordinate, preserving the sharp discrete spatial transition with zero spatial overshoot.

\subsection{Hardware and Complexity Implications}
A critical advantage of TimeFlowCodec lies in its decode memory access pattern. Standard HEVC-SCC Intra Block Copy (IBC) requires decoders to maintain large 2D on-chip SRAM search buffers to handle arbitrary 2D spatial displacement vectors. This creates complex routing barriers in silicon.

In contrast, TFC decoding consists of evaluating $\hat{s}(t) = a + b \cdot t$. For each pixel, parameters $(a, b)$ are read once per chunk and expanded into a linear frame buffer via contiguous, unit-stride memory writes. \section{Conclusion and Future Work}
This paper introduced TimeFlowCodec, an orthogonal video coding architecture designed specifically for screen and synthetic video. By discarding 2D spatial block transforms in favor of 1D per-pixel temporal regression with native 4:4:4 RGB representation, TFC eliminates Gibbs ringing artifacts around text edges and achieves an average $-26.8\%$ BD-Rate reduction over H.264 on JVET-SCC sequences. Furthermore, the absence of 2D spatial filtering enables sequential memory writes delivering $>260$~FPS decode performance.

Future research directions include:
\begin{enumerate}
    \item \textbf{AVX-512 and Metal Compute Kernels:} Accelerating the per-pixel OLS regression engine on modern SIMD hardware.
    \item \textbf{Hybrid Temporal-Spatial Mode Switching:} Integrating an adaptive classifier that dynamically transitions between 1D temporal regression and 2D spatial transforms for mixed screen/camera content.
\end{enumerate}
